# Voice Architecture

- **Téléphonie** : Telnyx Media Stream. Chaque environnement doit utiliser son application Call Control et un numéro dédié ; un numéro de production ne sert jamais au staging.
- **Reconnaissance** : Deepgram Nova-3 est le fournisseur principal. Cartesia Ink-2 reçoit en parallèle uniquement la voix de l'appelant et peut remplacer une phrase finale Deepgram si son résultat arrive dans le délai configuré. Si Deepgram tombe, Ink-2 peut prendre le relais en mode tours. Les secondes sont comptées séparément par fournisseur.
- **Dialogue** : le routage V2 garde au déterministe les réponses directes et non ambiguës. Les questions, corrections, contradictions et boucles sont traitées avec le contexte utile par le LLM ; une valeur interrogée n'est pas enregistrée comme choix confirmé.
- **Synthèse** : Cartesia Sonic 3.6 est le défaut téléphonique. ElevenLabs peut être sélectionné par configuration ; les chemins WebSocket et HTTP ont un repli vocal déterministe. Le cache distingue modèle, voix, locale, codec, réglages et prononciation.
- **Démonstration en direct (onboarding)** : le navigateur joue le rôle de Telnyx sur `/voice/demo-stream/:ticket` (A-law 8 kHz, protocole `start`/`media`/`mark`/`clear`). Le ticket à usage unique vient de `POST /restaurant/onboarding/live-demo` après authentification ; le WebSocket lui-même est public. La session porte `demo: true` : disponibilité et dialogue réels, mais réservation et message simulés, aucun transfert, aucun appel REST Telnyx ni finalisation d'appel. Un appel à la fois par restaurant, 180 s maximum, 20 essais par jour. Code : `apps/api/src/modules/voice/demo/`, client `apps/dashboard/src/features/onboarding/live-call/`.
- **Essais STT** : `DEEPGRAM_BENCH_API_KEY` et `CARTESIA_BENCH_API_KEY` doivent être dédiées et différentes des clés runtime. Le banc Cartesia impose aussi `BENCH_MAX_CREDITS`. Les scripts Scribe conservés sont historiques et hors runtime ; ne pas utiliser la clé ElevenLabs partagée pour un essai payant.
- **Activation** : aucun pilote client avant une recette téléphonique réelle en staging et la qualification des parcours d'échec, de réservation et de fin d'appel. Au 24/10/2026, le staging n'a pas de numéro Telnyx dédié rattaché à son application ; aucun appel réel ne doit y être lancé tant que ce prérequis n'est pas corrigé.

Pipeline : `apps/api/src/modules/voice/telnyx.pipeline.ts`. Détails et historique : `docs/obsidian/Telnyx Pipeline.md` et `docs/obsidian/Scribe Pipeline Media Stream.md`.
