# Fidélité manuelle : procédure en salle

La fidélité est disponible pour les établissements Pro et Multi-site. Le responsable ou le manager crée et attribue les attentions ; les membres de l’équipe peuvent consulter et valider une attribution en salle.

## Préparer une attention

1. Dans **Fidélité**, le responsable choisit **Créer une attention** et renseigne son nom, ses conditions, sa durée de validité et son nombre maximal d’utilisations par client. Il peut ajouter une consigne et un coût estimé.
2. Il sélectionne l’attention et le client, puis choisit **Attribuer l’attention**. L’attribution ne réussit que si le client respecte les conditions.
3. Le code apparaît une seule fois. Le responsable le remet au client et lui indique la date limite. Sokar ne l’envoie pas automatiquement ; si le code est perdu, demandez au responsable d’annuler l’attribution et d’en émettre une nouvelle si les conditions le permettent.

## Appliquer l’attention pendant le service

1. Demandez au client son code. Dans **Fidélité**, ouvrez **Valider une attention en salle** et sélectionnez l’attribution correspondant au client et à l’attention.
2. Vérifiez la date limite et les conditions affichées, saisissez le code puis choisissez **Valider l’attention**. Attendez la confirmation avant de servir l’attention ou de l’appliquer sur l’addition.
3. Appliquez ensuite l’avantage manuellement selon les consignes du responsable : Sokar ne modifie pas le ticket de caisse et ne déclenche aucun paiement.

Un code ne peut être consommé qu’une fois. Si la validation échoue, si l’attribution est expirée ou si le code est absent, ne l’appliquez pas sans avis du responsable. Une attribution expirée ne peut plus être validée ; son expiration est traitée automatiquement.

## Annuler une attribution

Avant consommation, le responsable ou le manager retrouve l’attribution dans **Fidélité**, choisit **Annuler l’attribution** et confirme. Elle ne pourra plus être validée. Une attention déjà consommée ne s’annule pas par cette procédure : prévenez le responsable pour traiter toute correction sur l’addition.
